# Combine Auto — лендинг

Публичный сайт: https://github.com/kostyanrmz/landingcombineauto

Next.js + React Three Fiber + Framer Motion. Скролл-сцена — облако точек с моделей комбайна и самосвала.

```bash
npm install 
npm run particles   # пересобрать точки из public/models/*.glb
npm run dev         # http://localhost:4177
```

Стиль — тёмный glass соседних лендингов (GPS Service / Burabay Food), палитра — зелёный логотипа Combine Auto. Основной приём — скролл-стори: по прокрутке перестраивается сцена уборки.

Модели (CC-BY, Sketchfab): John Deere CTS Combine — OwenNielsen; Japanese Dump Truck — Pavel Gorbachev.
